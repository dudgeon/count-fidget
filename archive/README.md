# Historical material

`rev0/` preserves superseded design notes, initial RFQ/display inquiries and partial calculator observations. Old 64-pin wiring, charge settings and compensation values are obsolete. Historical partial prices are not complete quotes.

`tooling/` preserves the original report/package builders for provenance. Their paths and embedded status are historical and their RFQ list omits the later BOM import correction. **Do not execute them for current output.** Use `scripts/package_rfq.py`. External compilers, KiCad/router distributions and downloaded vendor PDFs are not vendored here.
